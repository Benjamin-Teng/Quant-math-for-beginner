## Introduction

Volume III has built probability models for TAIEX's returns ([[LM13]] to [[LM17]]), and many questions about such a model have no formula. A Monte Carlo simulation answers them by drawing from the model many times. The bootstrap draws instead from the data's own empirical distribution. Both answers carry an error that the draws themselves measure.

> [!case] Under water after five years?
> TR23 is the TAIEX total-return index, dividends reinvested: 5,849 daily returns from 3 January 2003 to 8 October 2026. Five years is 1,231 sessions. Of the 4,619 five-year windows that start on a close in the sample, 191 ended below their start: 4.1%. All 191 started between November 2003 and April 2004 or between June and December 2007 ([[ex:windows]]). So they record two episodes, and the sample holds fewer than five non-overlapping five-year periods.
>
> A model of independent, normal daily log returns fitted to TR23 answers 5.49% by a formula. A Monte Carlo simulation of that model answers 5.3% ([[eg:mcase]]), and an iid bootstrap of the days 5.6% ([[eg:bcase]]), each ± 0.2 points with 10,000 draws. How far can each answer be trusted, and what does each one assume?

## Pseudo-Random Numbers and Seeds {lo=1}

A computer draws random numbers by arithmetic.

> [!example] Same seed, same answer {#seed}
> Count the draws at or below −2 among 10,000 standard normal draws from `default_rng([1, 20261011])`. Run it twice, then once more with `default_rng([16, 20261011])`.
>
> > [!solution]
> > The first run gives 249 hits, and the rerun gives 249 again, draw for draw. The second stream gives 214. Since $\Phi(-2)=0.02275$, the model expects 227.5 hits, and a binomial count has standard deviation $\sqrt{n\,p(1-p)}=14.9$ by (15.2). Both counts lie within 1.5 standard deviations of 227.5. A rerun reproduces a number; only a new stream replicates the experiment.

### The generator

A **pseudo-random number generator** is a deterministic recursion. A **seed** sets its internal state, and each step updates the state and outputs a number. NumPy's `default_rng(seed)` builds a `Generator` on the PCG64 algorithm, whose sequence repeats only after $2^{128}$ steps (O'Neill 2014; stated without proof).

The `Generator` turns the outputs into uniform draws on $[0,1)$. A random variable $U$ is **uniform**, $U\sim\operatorname{Unif}(0,1)$, when $\Pr(U\le u)=u$ for $0\le u\le1$. The draws are designed to behave like iid uniform draws, independent as in (16.1). This book does not test generators.

### One stream per experiment

Every simulated experiment in this module creates its generator once, at its start, as `default_rng([e, 20261011])`, with `e` the experiment's number. [[eg:gap]] alone keeps [[LM12]]'s seed, because it re-runs that lab. Each experiment has its own generator, so resizing one leaves the others unchanged. Through NumPy's `SeedSequence`, different values of `e` give streams that are independent with very high probability. A generator reseeded inside a loop would repeat its draws.

Rerunning with the same seed **reproduces** a result exactly, which checks the code, not the estimate. Running with another seed **replicates** the experiment, and the spread of the replications shows the simulation error. NumPy promises identical streams only for the same version and build, so the printed numbers rest on the NumPy that `uv.lock` pins.

> [!pitfall] Bump and reprice with common random numbers
> Bumping and repricing a Monte Carlo value with [[LM2]]'s central difference (2.11) divides the difference of two simulations by a small step, which magnifies their errors. With **common random numbers**, both runs use the same draws, so most of their errors cancel. For the slope of $\Pr(Z\le-k)$ at $k=2$ with $\Delta k=0.01$ and 100,000 draws a side, the standard error falls from 0.0333 to 0.0052 (Problem 11).

> [!zh] 隨機種子：重現不等於重複實驗
> 電腦產生的隨機數（random number）其實是擬隨機數（pseudo-random number）：擬隨機數產生器（pseudo-random number generator）是確定的遞迴（recursion），隨機種子（random seed）決定起始狀態，之後每一步都算得出來。它的輸出設計成像獨立同分布（iid）的均勻分布（uniform distribution）抽樣，這正是蒙地卡羅法（Monte Carlo method）需要的模型。同一個種子重跑一次，每個數字都一模一樣，只證明程式沒變，不是第二次檢驗；換一個種子才是重複實驗，結果之間的差距就是模擬誤差。本模組每個實驗（重跑 LM12 的 [[eg:gap]] 除外）在開頭建立一次自己的產生器 `default_rng([e, 20261011])`，之後不再重設。用中央差分（central difference）估計導數（derivative）時，兩邊的計算要共用同一組隨機數（common random numbers），誤差才會大部分抵銷。

> [!kc]
> A colleague reruns your simulation with the same seed and gets the same estimate. Is that a second check of the estimate?
>
> > [!answer]-
> > No. The same seed repeats every draw, so the rerun checks the code, not the simulation error. A new stream replicates the experiment, and the gap between 249 and 214 hits in [[eg:seed]] shows the error.

## From Uniform Draws to Any Distribution {lo=2}

A uniform draw $u$ can be read as a probability level. In [[ex:invtr]], mark $u$ on the vertical axis of TR23's empirical distribution function $\hat F$, (13.12), move right to the first step that reaches $u$, and read the return below. That return is the empirical quantile $\hat F^{-1}(u)=R_{(\lceil uT\rceil)}$ of [[LM14]].

> [!theorem] Inverse transform
> Let $U\sim\operatorname{Unif}(0,1)$, and let $F_Y$ be a distribution function with [[LM14]]'s quantile function $F_Y^{-1}(u)=\min\{y:F_Y(y)\ge u\}$ for $0<u<1$. Then
> $$\Pr\big(F_Y^{-1}(U)\le y\big)=F_Y(y)\quad\text{for every }y, \tag{18.1}$$
> so $F_Y^{-1}(U)$ has distribution function $F_Y$.

When $F_Y$ is continuous and strictly increasing, $F_Y^{-1}$ is its ordinary inverse and is increasing. So $F_Y^{-1}(U)\le y$ exactly when $U\le F_Y(y)$, an event of probability $F_Y(y)$ (Grinstead and Snell 1997, §5.2, Corollary 5.2). Deep Dive (a) proves the general case (Glasserman 2003, §2.2.1).

> [!deepdive]- (a) Proof of (18.1) for any distribution function
> Here $F_Y$ is any distribution function: non-decreasing, right-continuous, with limits 0 and 1 ([[LM13]]). Fix $u$ in $(0,1)$. The set $\{y:F_Y(y)\ge u\}$ is not empty, because $F_Y\to1$, and bounded below, because $F_Y\to0$. Right-continuity carries $F_Y\ge u$ from the set to its infimum, so the infimum is a minimum and $F_Y\big(F_Y^{-1}(u)\big)\ge u$.
>
> Now $F_Y^{-1}(u)\le y$ if and only if $u\le F_Y(y)$. If $u\le F_Y(y)$, then $y$ lies in the set, so the minimum is at most $y$. If $F_Y^{-1}(u)\le y$, then $F_Y(y)\ge F_Y\big(F_Y^{-1}(u)\big)\ge u$, since $F_Y$ is non-decreasing. Hence $\Pr\big(F_Y^{-1}(U)\le y\big)=\Pr\big(U\le F_Y(y)\big)=F_Y(y)$. $\blacksquare$

**The exponential distribution.** A waiting time $Y\ge0$ with $F_Y(y)=1-e^{-\lambda y}$ follows $\operatorname{Exp}(\lambda)$, with rate $\lambda>0$. Solving $u=1-e^{-\lambda y}$ gives $F_Y^{-1}(u)=-\ln(1-u)/\lambda$. Its mean is $1/\lambda$ (integrate by parts, [[LM5]]), and its median is $\ln2/\lambda$, the $y$ with $F_Y(y)=1/2$.

**Normal draws.** For the standard normal, $\Phi^{-1}(U)\sim\mathcal N(0,1)$, and $\mu+\sigma\Phi^{-1}(U)\sim\mathcal N(\mu,\sigma^2)$ by (15.6).

**Days from $\hat F$.** The rank $\lceil uT\rceil$ equals $j$ exactly when $(j-1)/T<u\le j/T$, an interval of length $1/T$. So the inverse transform on $\hat F$ draws each of the $T$ days with probability $1/T$: it picks a day uniformly at random.

> Experiment 2's generator `default_rng([2, 20261011])` gives `random(3)` = 0.1396965, 0.4634985 and 0.1740834 (seven decimals). Turn them into waiting times between days with $\lvert R\rvert\ge3\%$ under an exponential model, and into TAIEX days drawn from $\hat F$.
>
> > [!solution]
> > TR23 has 175 days with $\lvert R\rvert\ge3\%$ ([[LM14]]), so the model's rate is $\lambda=175/5{,}849=0.02992$ per session. The waits $-\ln(1-u)/\lambda$ are 5.03, 20.81 and 6.39 sessions. The model's mean wait is $1/\lambda=33.42$ sessions and its median $\ln2/\lambda=23.17$.
> >
> > For $\hat F$, the ranks $\lceil5{,}849u\rceil$ are 818, 2,712 and 1,019; seven decimals matter, since $5{,}849\times0.4634985=2{,}711.003$. The draws are $R_{(818)}=-0.9468\%$ (2021-12-14), $R_{(2712)}=+0.0247\%$ (2007-02-01) and $R_{(1019)}=-0.7785\%$ (2005-09-23), the points of [[ex:invtr]]. The waits are model values, while the three returns are real days.

**Normal vectors.** For $N$ independent standard normal draws $\mathbf Z$ and $LL^{\top}=\Sigma$, (16.7) gives $L\mathbf Z\sim\mathcal N_N(\mathbf 0,\Sigma)$, the colouring of [[LM12]] (Glasserman 2003, §2.3.3). Section 4 measures how close a coloured sample comes to $\Sigma$.

> [!pitfall] A uniform draw can be 0
> `Generator.random` returns numbers in $[0,1)$, and 0 is possible. Then $-\ln U$ is infinite and $\lceil TU\rceil=0$ is no rank, while $1-U$ lies in $(0,1]$. Draw waits as $-\ln(1-U)/\lambda$, and draw ranks with `integers(0, T)`, which returns the indices 0 to $T-1$ directly.

> [!zh] 逆變換法：把機率水準換成數值
> 逆變換法（inverse transform）把均勻分布（uniform distribution）的抽樣 $u$ 當成機率水準，再用分位數函數（quantile function）換成任何分布的抽樣：$F_Y^{-1}(U)$ 的累積分布函數（distribution function）就是 $F_Y$。指數分布（exponential distribution）的等待時間（waiting time）是 $-\ln(1-U)/\lambda$，常態分布（normal distribution）的抽樣是 $\Phi^{-1}(U)$，多變量常態分布（multivariate normal distribution）的向量則用 $L$ 著色（colouring）。對經驗分布函數（empirical distribution function）$\hat F$ 做逆變換，等於從 5,849 個交易日中等機率挑一天，這是第 7 節自助重抽法（bootstrap）的基礎。`random` 可能剛好抽到 0，所以等待時間要用 $-\ln(1-U)/\lambda$，排名則直接用 `integers` 抽。

> [!kc]
> Why is $-\ln U/\lambda$ also an $\operatorname{Exp}(\lambda)$ draw, and which return does $u=0.5$ draw from $\hat F$?
>
> > [!answer]-
> > If $U$ is uniform, so is $1-U$, so $-\ln U/\lambda$ has the law of $-\ln(1-U)/\lambda$; only $U=0$ must be avoided. For $u=0.5$ the rank is $\lceil2{,}924.5\rceil=2{,}925$, and $R_{(2925)}=+0.0879\%$ is TR23's median ([[LM14]]).

## The Monte Carlo Estimator and Its Error {lo=3}

Every answer the case asks for is an expectation: a probability is $\E[\mathbf 1_{\mathcal A}]$ by (14.1), and the mean growth factor is $\E G$. For a standard normal $Z$, $\E h(Z)=\int h(z)\varphi(z)\,dz$ by (5.9), and a path of $m$ days is an integral in $m$ dimensions. The **Monte Carlo estimator** replaces the integral by the average of $n$ independent draws.

> [!theorem] The Monte Carlo estimator
> Let $Y_1,\dots,Y_n$ be iid draws of $Y$ with $\E\lvert Y\rvert<\infty$, and $\bar Y_n=\frac1n\sum_iY_i$. Then $\E\bar Y_n=\E Y$, and $\bar Y_n\to\E Y$ with probability one as $n\to\infty$. If also $\sigma_Y^2<\infty$,
> $$\Var\bar Y_n=\frac{\sigma_Y^2}{n},\qquad\text{standard error }\frac{s_Y}{\sqrt n}. \tag{18.2}$$

The mean and the variance are (17.1), and the convergence is the strong law of [[LM17]] (Durrett 2019, Theorem 2.4.1). The **standard error** $s_Y/\sqrt n$ estimates the standard deviation of $\bar Y_n$ from the draws themselves. It shrinks like $1/\sqrt n$, so ten times the accuracy costs a hundred times the draws.

By the central limit theorem (17.5), $\bar Y_n$ is close to normal for large $n$, so it lies within $1.96\,\sigma_Y/\sqrt n$ of $\E Y$ with probability close to 0.95. With $s_Y$ for $\sigma_Y$, this gives the **95% Monte Carlo interval**

$$\bar Y_n\pm1.96\,\frac{s_Y}{\sqrt n},\qquad0<\sigma_Y^2<\infty,\ n\text{ large}. \tag{18.3}$$

The interval (18.3) misses $\E Y$ in about one run in twenty. It is approximate: close with thousands of draws, but not when the draws contain few hits of a rare event (Section 5). [[LM20]] develops standard errors and confidence intervals for data. A printed estimate keeps only the digits its standard error supports: $0.0530\pm0.0022$ prints as 5.3% ± 0.2 points.

**Other standard errors.** An indicator $Y=\mathbf 1_{\mathcal A}$ has $Y^2=Y$, so $\sigma_Y^2=p(1-p)$ and the standard error is $\sqrt{\hat p(1-\hat p)/n}$. For near-normal draws, $s_Y^2$ has relative standard error about $\sqrt{2/n}$ by $\Var(Z^2)=2$, (14.6). A square root halves a small relative error ([[LM2]]'s tangent line), so $s_Y$ has standard error about $s_Y/\sqrt{2n}$.

For a quantile or a slope, compute the statistic on 20 equal batches of the draws. For large $n$ its variance falls about like $1/n$, as (17.1) gives for a mean (stated without proof; Glasserman 2003, §9.1.2, for a quantile; [[LM23]] for a slope). So a batch 20 times smaller gives about 20 times the variance, and the standard deviation of the 20 values (divisor 20) over $\sqrt{20}$ approximates the standard error.

> [!example] The case by simulation {#mcase}
> In the case's model, daily log returns are iid $\mathcal N(g,\sigma_r^2)$ with $g=\bar r=0.05517\%$ and $\sigma_r=s_r=1.2107\%$. Find $\Pr(G<1)$ for $m=1{,}231$ sessions exactly, then from 10,000 paths simulated with `default_rng([3, 20261011])`.
>
> > [!solution]
> > By (1.12), $\ln G=\sum_tr_t$ is a sum of $m$ iid normal log returns, so $\ln G\sim\mathcal N(mg,m\sigma_r^2)$ by (16.7), and (17.6) holds exactly. Hence $\Pr(G<1)=\Phi(-g\sqrt m/\sigma_r)=\Phi(-1.5988)=5.49\%$.
> >
> > Experiment 3 draws `standard_normal((500, m))` twenty times and sums $g+\sigma_rZ_t$ along each row. Of the 10,000 paths, 530 end under water, so $\hat p=0.0530$ with standard error $\sqrt{0.0530\times0.9470/10{,}000}=0.0022$. The 95% Monte Carlo interval, about 4.9% to 5.7%, covers 5.49%, and the simulation reports 5.3% ± 0.2 points.

### Why LM12's colouring gap was 0.0250

[[LM12]]'s lab coloured 4,382 standard normal vectors with S5's Cholesky factor. Their covariance matrix missed $\Sigma$ by a relative 0.0250, and the lab left the rate to this module. Let $\mathbf X_1,\dots,\mathbf X_n$ be iid $\mathcal N_N(\mathbf 0,\Sigma)$, and let $\hat\Sigma_{\text{sim}}=\frac1n\sum_i\mathbf X_i\mathbf X_i^{\top}$. Measure the gap with the **Frobenius norm** $\lVert M\rVert_F$, the square root of the sum of the squared entries. Deep Dive (b) proves

$$\E\lVert\hat\Sigma_{\text{sim}}-\Sigma\rVert_F^2=\frac{\lVert\Sigma\rVert_F^2+(\operatorname{tr}\Sigma)^2}{n}. \tag{18.4}$$

The root-mean-square relative gap is therefore

$$\frac{\big(\E\lVert\hat\Sigma_{\text{sim}}-\Sigma\rVert_F^2\big)^{1/2}}{\lVert\Sigma\rVert_F}=\sqrt{\frac{1+(\operatorname{tr}\Sigma)^2/\lVert\Sigma\rVert_F^2}{n}},$$

a $1/\sqrt n$ rate again.

> [!example] Was a gap of 0.0250 large? {#gap}
> LM12's lab drew `standard_normal((4382, 5))` from `default_rng(20261011)`, coloured the rows with S5's factor $L$ and compared `np.cov(..., ddof=0)` of the result with $\Sigma=LL^{\top}$. Here its 4,382 draws are $n$.
>
> > [!solution]
> > The same draws, coloured with LM12's printed $L$, give the gap 0.0250. Semiconductor's simulated variance, for example, is 4.18% too high, about two standard errors of $\sqrt{2/n}=\sqrt{2/4{,}382}=2.14\%$, since $\Var(Z^2)=2$.
> >
> > For S5, $(\operatorname{tr}\Sigma)^2/\lVert\Sigma\rVert_F^2=2.6509$, so the root-mean-square relative gap is $1.911/\sqrt n$: 0.0289 at $n=4{,}382$ and 0.0085 at 50,000. In [[ex:rate]], 82 of 200 runs (41%) come at or below 0.0250, so LM12's run was ordinary.

> [!deepdive]- (b) Proof of (18.4)
> Let $X_1$ and $X_2$ be two entries of $\mathbf X\sim\mathcal N_N(\mathbf 0,\Sigma)$, bivariate normal by (16.7), with standard deviations $\sigma_1$, $\sigma_2$ and correlation $\rho_{12}$. The matching entries of $\Sigma$ are $\sigma_{11}=\sigma_1^2$, $\sigma_{22}=\sigma_2^2$ and $\sigma_{12}=\rho_{12}\sigma_1\sigma_2$. Colour them with their own $2\times2$ factor, for independent standard normal $Z_1$ and $Z_2$:
> $$\begin{gathered}X_1=\sigma_1Z_1,\\ X_2=\sigma_2\big(\rho_{12}Z_1+\sqrt{1-\rho_{12}^2}\,Z_2\big).\end{gathered}$$
> Then $X_1X_2=\sigma_1\sigma_2\big(\rho_{12}Z_1^2+\sqrt{1-\rho_{12}^2}\,Z_1Z_2\big)$, and the two terms are uncorrelated because $\E[Z_1^3Z_2]=0$. With $\Var(Z_1^2)=2$ from (14.6) and $\Var(Z_1Z_2)=1$,
> $$\begin{aligned}\Var(X_1X_2)&=\sigma_{11}\sigma_{22}\big(2\rho_{12}^2+1-\rho_{12}^2\big)\\&=\sigma_{11}\sigma_{22}+\sigma_{12}^2 .\end{aligned}$$
> The same steps give $\Var(X_1^2)=2\sigma_{11}^2$, the formula with both entries equal. Each entry of $\hat\Sigma_{\text{sim}}$ is a mean of $n$ iid copies of such a product, and its mean is the matching entry of $\Sigma$. By (17.1) its expected squared error is the product's variance over $n$.
>
> Summing over all $N^2$ positions of $\Sigma$, the terms $\sigma_{11}\sigma_{22}$ add up to $(\operatorname{tr}\Sigma)^2$ and the terms $\sigma_{12}^2$ to $\lVert\Sigma\rVert_F^2$, which is (18.4). The call `np.cov(..., ddof=0)` centres the draws first, which changes the root-mean-square gap by under 0.4% for S5 when $n\ge100$. $\blacksquare$

> [!pitfall] The interval measures simulation error only
> The interval of [[eg:mcase]] says that more paths would bring the estimate close to 5.49%, the model's own answer. It says nothing about TAIEX, because the model assumes independent normal days fitted to the whole sample. The formula is exact under the model; every simulated number only approximates it.

> [!zh] 蒙地卡羅估計：誤差以 $1/\sqrt n$ 的速度縮小
> 蒙地卡羅法（Monte Carlo method）把期望值（expectation）寫成積分（integral），再用 $n$ 個獨立同分布（iid）抽樣的平均去估計它。強大數法則（strong law of large numbers）保證平均會收斂，標準誤（standard error）$s_Y/\sqrt n$ 則告訴我們誤差有多大：精確度要提高 10 倍，抽樣數就得增加 100 倍。由中央極限定理（central limit theorem），「估計值 ± 1.96 個標準誤」是 95% Monte Carlo interval，也就是只量模擬誤差的區間，不是對台股的信賴區間（confidence interval）。印出的位數要配合標準誤：$0.0530\pm0.0022$ 只能寫成 5.3% ± 0.2 個百分點。下一節會看到，這個速度與維度無關，所以高維度時模擬通常比格點上的數值積分（quadrature）有效率，只是單次抽樣的標準差（standard deviation）$\sigma_Y$ 可能隨維度變大。

> > [!answer]-
> > The standard error is $\sqrt{p(1-p)/n}$, so $n=p(1-p)/0.001^2=0.0549\times0.9451/10^{-6}$, about 52,000 paths, five times as many as [[eg:mcase]] used.

### Antithetic variates

Since $-\mathbf Z$ has the same law as $\mathbf Z$, the partner $Y_i^-=h(-\mathbf Z_i)$ of $Y_i=h(\mathbf Z_i)$ has the same law as $Y_i$. Average each pair. By (16.3), $\Var\big(\tfrac12(Y_i+Y_i^-)\big)=\tfrac14\sigma_Y^2(2+2\rho_-)$, so for $n$ pairs, independent across $i$, and $\sigma_Y^2<\infty$,

$$\begin{gathered}\Var\Big(\frac1n\sum_{i=1}^n\tfrac12(Y_i+Y_i^-)\Big)\\=\frac{\sigma_Y^2}{2n}(1+\rho_-).\end{gathered} \tag{18.5}$$

Plain sampling with the same $2n$ evaluations has variance $\sigma_Y^2/(2n)$. So antithetic pairs multiply the variance by $1+\rho_-$, and they help only when $\rho_-<0$. When $Y=h(\mathbf Z)$ with $h$ non-decreasing in every coordinate (or non-increasing in every one), $\rho_-\le0$ (stated without proof; Glasserman 2003, §4.2, p. 207).

> [!example] Antithetic paths {#anti}
> Estimate the model's five-year mean growth factor $\E G$ with 5,000 antithetic pairs from `default_rng([6, 20261011])`, and compare with the 10,000 plain paths of [[eg:mcase]].
>
> > [!solution]
> > By (5.12), $\E G=e^{m(g+\sigma_r^2/2)}=2.1584$. Experiment 6 draws `standard_normal((500, m))` ten times, and builds a path from each row $\mathbf Z$ and its partner from $-\mathbf Z$. The 5,000 pairs give $2.155\pm0.004$, against $2.165\pm0.010$ from the plain paths.
> >
> > The partner of $G$ is $e^{2mg}/G$, and $G$ increases in every $Z_t$. By Problem 5, $\rho_-=-e^{-m\sigma_r^2}=-0.835$ with $m\sigma_r^2=0.1804$, so the variance falls by the factor $1/(1+\rho_-)=6.06$. For $\Pr(G<1)$ the pairs give $0.0528\pm0.0022$: a path and its partner cannot both end under water, so $\rho_-=-p/(1-p)=-0.058$ with $p=0.0549$, a factor of only 1.06.

### Control variates

Suppose each draw also yields a quantity $X$ whose mean $\mu_X$ is known exactly, such as $\ln G$ with mean $mg$. Then $Y-\beta(X-\mu_X)$ has the mean of $Y$ for every constant $\beta$. By (16.3) its variance is $\sigma_Y^2-2\beta\sigma_{XY}+\beta^2\sigma_X^2$, smallest at $\beta=\sigma_{XY}/\sigma_X^2$. Hence, for iid pairs $(X_i,Y_i)$ with finite variances, $\sigma_X>0$ and known $\mu_X$,

$$\begin{gathered}\Var\big(\bar Y_n-\beta(\bar X_n-\mu_X)\big)=\frac{(1-\rho_{XY}^2)\,\sigma_Y^2}{n}\\ \text{at}\quad\beta=\frac{\sigma_{XY}}{\sigma_X^2}.\end{gathered} \tag{18.6}$$

The best $\beta$ is the least-squares slope of $Y$ on $X$, so $\hat\beta$ comes from the draws as in (12.3) of [[LM12]]. Estimating $\beta$ from the same draws adds a bias, typically of order $1/n$ (stated without proof; Glasserman 2003, §4.1.3).

> [!example] A control variate for the five-year mean {#control}
> On the paths of [[eg:mcase]], use $X=\ln G$, whose mean $mg=0.6791$ is known, as a control for $Y=G$ and for $Y=\mathbf 1\{G<1\}$.
>
> > [!solution]
> > The least-squares slope of $G$ on $\ln G$ is $\hat\beta=2.18$ (batch standard error 0.01). Exactly, $\beta=\E G=2.1584$, because completing the square as in (5.12) gives $\Cov(G,\ln G)=m\sigma_r^2\,\E G$. The controlled estimate is $2.161\pm0.003$, against $2.165\pm0.010$ plain.
> >
> > The exact correlation of the control with $Y=G$ is
> > $$\rho_{XY}=\Big(\frac{m\sigma_r^2}{e^{m\sigma_r^2}-1}\Big)^{1/2}=0.955,$$
> > and with the indicator $Y=\mathbf 1\{G<1\}$ it is
> > $$\rho_{XY}=-\frac{\varphi(1.5988)}{\sqrt{p(1-p)}}=-0.488.$$
> > The variance falls by the factor $1/(1-\rho_{XY}^2)$: 11.4 for $G$, but only 1.31 for the indicator, whose controlled estimate is $0.0535\pm0.0020$.

### Importance sampling

A tail event is rare under $\mathcal N(0,1)$ but common under a normal shifted towards it (Glasserman 2003, §4.6). Completing the square gives $\varphi(z)e^{az-a^2/2}=\varphi(z-a)$. Substituting $x=z-a$ in (5.9) then gives, for every $a$ and every $h$ with $\E\lvert h(Z)\rvert<\infty$,

$$\begin{gathered}\E h(Z)=\E\big[h(Z-a)\,e^{aZ-a^2/2}\big],\\ \Pr(Z\le-k)=\E\big[\mathbf 1\{Z\le0\}\,e^{kZ-k^2/2}\big].\end{gathered} \tag{18.7}$$

The second line takes $a=k$: the shifted draw $Z-k$ lands in the tail about half the time, and the weight $e^{kZ-k^2/2}$ corrects for the shift. Deep Dive (c) gives the second moment of one draw, $e^{k^2}\Phi(-2k)$ at $a=k$. [[LM32]] applies these estimators to value at risk.

> [!example] Importance sampling for LM5's tail {#impsamp}
> Estimate $p=\Pr(Z\le-4.1074386)$ by (18.7) with $a=k=4.1074386$ from 10,000 draws of `default_rng([8, 20261011])`.
>
> > [!solution]
> > Experiment 8 draws `standard_normal(10_000)`. Of the shifted draws $Z-k$, 5,043 land in the tail, and the weighted average is $2.047\times10^{-5}\pm0.044\times10^{-5}$, a relative standard error of 2.1%. The exact $2.000355\times10^{-5}$ lies inside its 95% Monte Carlo interval.
> >
> > By Deep Dive (c), one draw has variance $e^{k^2}\Phi(-2k)-p^2=1.8546\times10^{-9}$, against $p(1-p)=2.0003\times10^{-5}$ for a plain draw. The ratio is 10,786, so these 10,000 draws do the work of $1.08\times10^8$ plain ones. Three significant digits would give 10,811.

> [!deepdive]- (c) The second moment of importance sampling
> One draw of (18.7) for $h(z)=\mathbf 1\{z\le-k\}$ is $Y=\mathbf 1\{Z\le a-k\}e^{aZ-a^2/2}$, so $Y^2=\mathbf 1\{Z\le a-k\}e^{2aZ-a^2}$. Completing the square, $\varphi(z)e^{2az}=e^{2a^2}\varphi(z-2a)$, so
> $$\begin{aligned}\E[Y^2]&=e^{a^2}\int_{-\infty}^{a-k}\varphi(z-2a)\,dz\\&=e^{a^2}\Phi(-k-a).\end{aligned}$$
> At $a=k$ the second moment is $e^{k^2}\Phi(-2k)$, and the variance of one draw is $e^{k^2}\Phi(-2k)-p^2$. $\blacksquare$

> [!pitfall] A shift too far out
> The relative standard error of one draw, $\sqrt{e^{a^2}\Phi(-k-a)-p^2}/p$, is 7.76 at $a=k/2$, 2.15 at $a=k$ and 132 at $a=2k$, against 223.6 for a plain draw. Shifted too far, most draws land deep in the tail with tiny weights, and a rare draw near the threshold carries a huge one. The shifted law must also be positive wherever $h\varphi\ne0$, as a normal always is.

> [!zh] 變異數縮減：同樣的抽樣數，更小的誤差
> 變異數縮減（variance reduction）不改變估計的期望值（expectation），只改變平均的對象。對偶變數（antithetic variates）把 $\mathbf Z$ 和 $-\mathbf Z$ 配成一對，相關係數（correlation coefficient）$\rho_-$ 為負時才有用：估計五年成長倍數（growth factor）的期望值時，估計值的變異數（variance）縮小 6.06 倍，但尾端機率的兩個事件（event）互斥（disjoint），幾乎沒有幫助。控制變量（control variate）利用期望值已知的 $\ln G$，變異數乘上 $1-\rho_{XY}^2$，最適係數就是最小平方法（least squares）的斜率（slope）。重要抽樣（importance sampling）把抽樣用的常態分布（normal distribution）平移到尾端，再用權重（weight）修正：估計 LM5 的 −5% 尾端機率時，估計值的變異數縮小 10,786 倍。移得太遠反而更糟，靠近門檻的少數抽樣會帶著極大的權重。

> [!kc]
> Why do antithetic pairs not help with $\Pr(Z\le-k)$?
>
> > [!answer]-
> > The pair is $\mathbf 1\{Z\le-k\}$ and $\mathbf 1\{Z\ge k\}$, which cannot both be 1. So $\E[Y_iY_i^-]=0$ and $\rho_-=-p^2/\big(p(1-p)\big)=-p/(1-p)$, only $-2.0\times10^{-5}$ at $k=4.1074386$. The variance falls by the factor 1.00002: a pair costs two evaluations and is worth two plain draws, no more.

## The iid Bootstrap {lo=6}

The model of Sections 4–6 assumed normal days. The iid **bootstrap** instead takes the empirical distribution $\hat F$, mass $1/T$ on each of TR23's returns, as the model (Efron and Tibshirani 1993, ch. 6). A **resample** draws days with replacement, each with probability $1/T$ at every draw, and `integers(0, T, size=T)` gives the indices. By Section 3, a resample is a set of iid draws from $\hat F$, as in (13.13).

Under $\hat F$, a drawn day has mean $\frac1T\sum_tR_t=\bar R$ and variance $\frac1T\sum_t(R_t-\bar R)^2=s^2$. A resample mean $\bar R_{\text{boot}}$ averages $T$ such iid days, so (17.1) gives

$$\E_{\hat F}\bar R_{\text{boot}}=\bar R,\qquad\Var_{\hat F}(\bar R_{\text{boot}})=\frac{s^2}{T}. \tag{18.8}$$

Both moments in (18.8) are exact properties of the bootstrap model. [[LM20]] derives the same $s/\sqrt T$ as the sampling error of $\bar R$.

> [!example] The bootstrap of the mean day {#bmean}
> With `default_rng([9, 20261011])`, draw $B=10{,}000$ resamples of 5,849 days, and compare the spread of their means with (18.8).
>
> > [!solution]
> > Experiment 9 draws `integers(0, T, size=(500, T))` twenty times. The resample means average $0.06272\%\pm0.00016\%$, against $\bar R=0.062505\%$, and their standard deviation (divisor $B$) is $0.01563\%\pm0.00011\%$, with standard error $s_Y/\sqrt{2B}$. By (18.8) the exact value is $s/\sqrt T=1.2084\%/\sqrt{5{,}849}=0.01580\%$, 1.5 standard errors away. Efron and Tibshirani's (6.6) divides by $B-1$, which changes nothing here. Wasserman (2004, §8.2) divides by $B$ in his (8.1), as this module does.

**The growth factor.** A resample of $m$ days has growth factor $G_{\text{boot}}$, the product of $1+R$ over its drawn days. These days are independent with mean $\bar R$, so (17.4) with $\mu=\bar R$ gives

$$\E_{\hat F}G_{\text{boot}}=(1+\bar R)^m. \tag{18.9}$$

The log of $G_{\text{boot}}$ is a sum of $m$ iid drawn log returns, with mean $m\bar r$ and variance $ms_r^2$ exactly, the two moments of the normal model of [[eg:mcase]]. Over 1,231 days the central limit theorem then makes the shape of one day matter little, so the two models agree.

### What resampling keeps and destroys

Every resampled day is one of TR23's days, so resampling keeps the one-day law exactly. The 15 days at or below −5% ([[LM13]]) recur at their own frequency, 7 April 2025 (−9.6997%) among them.

Resampling ignores the order of days, so it destroys their clustering. [[ex:destroy]] counts the days with $\lvert R\rvert\ge3\%$ in each calendar month. TR23 has three months with eight (September 2008, October 2008 and March 2020), and a monthly variance of 1.846 ([[LM15]]). Resamples placed on TR23's dates give 0.598, the value of independent days, and the lag-1 correlation of $\lvert r_t\rvert$ falls from 0.161 ([[LM17]]) to about 0.

Resampling blocks of days keeps part of the clustering ([[LM22]]); volatility that depends on yesterday's is the subject of [[LM26]].

> [!pitfall] Resampling days is not a test on later data
> The Research hygiene page says to split by time, never at random. A bootstrap draws days at random from the whole sample, mixing both limit regimes: 3,077 returns before 1 June 2015 and 2,772 from it. It shows how a statistic varies under the iid-days model; it is no test on later data ([[LM34]]). Reading a range of resamples as an interval for TAIEX is bootstrap inference, left to [[LM22]].

> [!zh] 自助重抽法：保留單日分布，破壞群聚
> 自助重抽法（bootstrap）把經驗分布（empirical distribution）$\hat F$ 當成模型：重抽樣（resampling）是放回抽樣（sampling with replacement），每次以 $1/T$ 的機率挑一天，所以一組重抽樣就是獨立同分布（iid）的抽樣。放回重抽樣（resampling with replacement）的平均數（mean），期望值（expectation）正好是 $\bar R$、變異數（variance）正好是 $s^2/T$，成長倍數（growth factor）的期望值是 $(1+\bar R)^m$。它保留了單日的分布，2025 年 4 月 7 日的 −9.70% 照樣可能被抽到；但它打亂了日期順序，波動的群聚（volatility clustering）完全消失：每月大波動日數的變異數從 1.846 掉到 0.598。所以自助重抽法量的是「各日獨立（independent）」這個模型下的變化，不是對未來資料的檢定。

> | `rng.choice(a, size)` | draws from the entries of `a` | `replace=True` by default |
> | `rng.multivariate_normal(mean, cov)` | normal vectors | factors `cov` by SVD by default |
> | `np.cov(x, rowvar=False)` | covariance of the columns | divisor $n-1$ unless `ddof=0` |
> | `np.quantile(x, u, method="inverted_cdf")` | order statistic $x_{(\lceil un\rceil)}$ | the default interpolates |
> | `stats.norm.ppf(u)` | $\Phi^{-1}(u)$ | |
>
> Note: NumPy 2.5 and SciPy 1.18 references, checked against NumPy 2.5.3 and SciPy 1.18.1; `rng` is a `Generator`.

**One generator per experiment, in chunks.** Create the generator once, at the start of the experiment, and draw each path as a row, so that $\ln G$ is a row sum by (1.12). The code below is [[eg:mcase]]:

```python
import numpy as np
from scipy import stats

m, g, sr = 1231, 0.0005517, 0.012107           # sessions, rbar, s_r
rng = np.random.default_rng([3, 20261011])      # experiment 3, once
lnG = np.empty(10_000)
for c in range(0, 10_000, 500):                 # 20 chunks of 500 paths
    z = rng.standard_normal((500, m))
    lnG[c:c + 500] = (g + sr * z).sum(axis=1)   # ln G as a sum (1.12)
y = (lnG < 0).astype(float)
print(y.mean(), y.std() / np.sqrt(y.size))      # 0.053 0.00224...
print(stats.norm.cdf(-g * np.sqrt(m) / sr))     # 0.0549...
```

Chunks keep the memory small, and they double as the batches of a batch standard error.

> [!pitfall] Another method draws other numbers
> A seed fixes a stream of bits, not the draws of every method. From `default_rng([2, 20261011])`, `norm.ppf(rng.random(3))` gives −1.0817, −0.0916 and −0.9382, while `standard_normal(3)` from a generator re-created with that seed gives 0.1679, 0.2891 and 0.7095. Likewise `multivariate_normal` gives other vectors than `standard_normal((n, N)) @ L.T`, because it factors the covariance matrix by SVD. Keep the method fixed when a result must reproduce.

## Summary {-}

- A seed reproduces every draw; another seed replicates the experiment.
- The inverse transform (18.1) turns uniform draws into exponential, normal and empirical draws, and colouring gives normal vectors.
- A Monte Carlo mean has standard error $s_Y/\sqrt n$, (18.2), and a 95% Monte Carlo interval, (18.3), for simulation error only. LM12's gap of 0.0250 was an ordinary run of (18.4).
- Quadrature wins in one dimension; in $N$ dimensions a grid errs by $O(n^{-4/N})$, Monte Carlo by $O(n^{-1/2})$.
- Antithetic variates (18.5), control variates (18.6) and importance sampling (18.7) keep the mean and cut the variance.
- The iid bootstrap draws days from $\hat F$, with (18.8) and (18.9) exact. It agrees with the normal model on the case because both give $\ln G$ the same mean and variance.
- Resampling keeps the one-day law and destroys the clustering.

## Solutions {-}

1. **B** is correct. By (18.2) the standard error is $s_Y/\sqrt n$, so dividing it by 10 needs $\sqrt n$ ten times larger, $n$ a hundred times larger. A treats the error as $1/n$, and C inverts the square root.

2. **C** is correct. For an indicator $\sigma_Y^2=p(1-p)$, so the standard error is $\sqrt{0.001350\times0.998650/10^6}=3.67\times10^{-5}$. A, 0.0367, forgets $n$, and B, $1.35\times10^{-9}$, is the variance of $\hat p$, not its standard deviation.

3. **A** is correct, by (18.1) with $F_Y^{-1}(u)=-\ln(1-u)/\lambda$. B has mean $\lambda$ instead of $1/\lambda$: at $\lambda=0.02992$ its waits average 0.03 sessions instead of 33.4. C applies $F_Y$ instead of $F_Y^{-1}$, and its values stay below $1-e^{-0.02992}=0.0295$.

4. Sorted, the returns are −2.5%, −0.8%, +0.3%, +0.6% and +1.2%. The ranks are $\lceil1.85\rceil=2$, $\lceil4.75\rceil=5$ and $\lceil0.9\rceil=1$, so the draws are −0.8%, +1.2% and −2.5%. For $u=0$, $\lceil5\times0\rceil=0$ is no rank: every $x$ has $\hat F(x)\ge0$, so the set in $\hat F^{-1}(0)$ has no minimum.

5. (a) By (18.5), antithetic pairs multiply the variance by $1+\rho_-$, so the standard error by $\sqrt{1+\rho_-}$: $0.0097\sqrt{1-0.835}=0.0039$ for $\E G$ and $0.0022\sqrt{1-0.058}=0.0021$ for $\Pr(G<1)$, close to [[eg:anti]]'s results.

   (b) Under the model, $\ln G\sim\mathcal N(mg,m\sigma_r^2)$. The partner path has $\ln G^-=2mg-\ln G$, so $GG^-=e^{2mg}$, and $G^-$ has the law of $G$. By (5.12), applied to $\ln G$ and to $2\ln G$,
   $$\begin{aligned}\E G&=\E G^-=e^{mg+m\sigma_r^2/2},\\ \E G^2&=e^{2mg+2m\sigma_r^2},\\ \Cov(G,G^-)&=e^{2mg}-(\E G)^2\\&=-e^{2mg}\big(e^{m\sigma_r^2}-1\big),\\ \Var G&=\E G^2-(\E G)^2\\&=e^{2mg+m\sigma_r^2}\big(e^{m\sigma_r^2}-1\big).\end{aligned}$$
   The ratio of the covariance to the variance is $\rho_-=-e^{-m\sigma_r^2}$.

6. **B** is correct. By (18.6) the variance falls by the factor $1-\rho_{XY}^2=1-0.95^2=0.0975$, so one controlled draw is worth $1/0.0975=10.3$ plain draws. A, 1.11, is $1/\rho_{XY}^2$, and C, 20, is $1/(1-\rho_{XY})$, which forgets the square.

7. Completing the square gives $\varphi(z)e^{az-a^2/2}=\varphi(z-a)$, so
   $$\begin{aligned}&\E\big[h(Z-a)\,e^{aZ-a^2/2}\big]\\&\quad=\int h(z-a)\,\varphi(z-a)\,dz=\E h(Z),\end{aligned}$$
   and the weight is $e^{aZ-a^2/2}$. Deep Dive (c) gives the second moment, $e^{k^2}\Phi(-2k)$ at $a=k$. For $k=3$, $p=\Phi(-3)=1.3499\times10^{-3}$ and $e^9\Phi(-6)=7.994\times10^{-6}$, so one draw has variance $6.17\times10^{-6}$. A plain draw has $p(1-p)=1.348\times10^{-3}$, 218 times as much.

8. A day drawn from $\hat F$ has mean $\bar R$ and variance $\frac1T\sum_t(R_t-\bar R)^2=s^2$. The $T$ days of a resample are iid, so by (17.1) their mean has variance $s^2/T$, and $s/\sqrt T=1.2084\%/\sqrt{5{,}849}=0.01580\%$. No: 0.01563% lies 1.5 of its standard errors, $s_Y/\sqrt{2B}=0.00011\%$, below the exact value, an ordinary simulation error.

9. By (17.4), $m$ independent days with mean $\mu$ give $\E W_m=W_0(1+\mu)^m$. Under $\hat F$ the resampled days are independent with mean $\bar R$, so $\E_{\hat F}G_{\text{boot}}=(1+\bar R)^m$, and $1.00062505^{1231}=2.1580$. The median path is close to $e^{m\bar r}=e^{1231\times0.0005517}=1.9722$ by (17.6), lower than the mean path ([[LM17]]).

10. **A** is correct. Monte Carlo's order $n^{-1/2}$ beats $n^{-4/N}$ when $4/N<1/2$, that is $N>8$. B uses the trapezoid rule's order $n^{-2/N}$, and C a first-order rule.

11. By (2.11) the exact central difference is $(0.0222156-0.0232955)/0.02=-0.0540$, equal to $-\varphi(2)$ at this precision. With independent draws the variances of the two sides, $0.0222156\times0.9777844$ and $0.0232955\times0.9767045$, add up to 0.044475. With common draws the difference counts the draws in $(-2.01,-1.99]$, an indicator with probability 0.0010799 and variance $0.0010799\times0.9989201=0.0010787$. The standard errors, independent and common, are
    $$\begin{gathered}\frac{\sqrt{0.044475/100{,}000}}{0.02}=0.0333,\\ \frac{\sqrt{0.0010787/100{,}000}}{0.02}=0.0052.\end{gathered}$$

12. With `R` TR23's daily simple returns as a NumPy array:

    ```python

    rng = np.random.default_rng([10, 20261011])          # experiment 10

    ```

## Glossary {-}

| Term | 中文 | Meaning |
|:--|:--|:--|
| Pseudo-random number generator | 擬隨機數產生器 | A deterministic recursion whose outputs behave like iid uniform draws. |
| Seed | 隨機種子 | The number, or list of numbers, that sets a generator's starting state. |
| Common random numbers | （兩次計算共用同一組隨機數） | The same draws in two runs whose difference is wanted, so that their errors cancel. |
| Uniform distribution | 均勻分布 | $\operatorname{Unif}(0,1)$: $\Pr(U\le u)=u$ for $0\le u\le1$. |
| Inverse transform | 逆變換法 | $F_Y^{-1}(U)$ has distribution function $F_Y$, (18.1). |
| Exponential distribution | 指數分布 | $\operatorname{Exp}(\lambda)$: $F_Y(y)=1-e^{-\lambda y}$, mean $1/\lambda$, median $\ln2/\lambda$. |
| Monte Carlo estimator | 蒙地卡羅估計量 | The mean $\bar Y_n$ of $n$ iid draws, an estimate of $\E Y$, (18.2). |
| Standard error | 標準誤 | $s_Y/\sqrt n$, the estimated standard deviation of $\bar Y_n$. |
| 95% Monte Carlo interval | （只量模擬誤差的區間） | $\bar Y_n\pm1.96\,s_Y/\sqrt n$, (18.3); it measures simulation error only. |
| Frobenius norm | Frobenius 範數 | $\lVert M\rVert_F$, the square root of the sum of the squared entries. |
| Variance reduction | 變異數縮減 | A change of what is averaged that keeps the expectation and lowers the variance. |
| Antithetic variates | 對偶變數 | Pairs of draws from $\mathbf Z$ and $-\mathbf Z$, (18.5). |
| Control variate | 控制變量 | A quantity with known mean that corrects the estimate, (18.6). |
| Importance sampling | 重要抽樣 | Drawing from a shifted law and weighting the draws back, (18.7). |
| Bootstrap | 自助重抽法 | Treating the empirical distribution $\hat F$ as the model and drawing from it. |
| Resampling with replacement | 放回重抽樣 | Drawing days from the sample, each with probability $1/T$ at every draw. |
