# Quant-math-for-beginner · From Calculus to Kelly

從大一的微積分、統計學與線性代數開始，一路推進到**自建統計模型、投資組合統計最佳化、計算真正的風險報酬，以及在估計誤差下求最適凱利槓桿**。全書 9 卷 50 個 Learning Modules，架構參考 CFA 課本（Learning Outcomes → 編號章節 → Example／Exhibit → Practice Problems → Solutions）。內文以英文為主，難懂之處附「中文導讀」；每章附 Jupyter Lab，用台股與美股真實資料重現書中每個數字。

*A nine-volume quantitative curriculum that starts from first-year calculus, statistics and linear algebra and ends with statistical models, optimized portfolios and growth-optimal (Kelly) leverage. English text with Traditional Chinese reading guides; every module ships with a lab notebook on real Taiwan and US market data.*

## Build

```bash
uv pip install -r build/requirements.txt
(cd build && npm ci)              # KaTeX + self-hosted fonts
./build.sh                        # docs/ (web) and dist/artifact/ (claude.ai artifact bundle)
./build.sh --pdf                  # also render docs/pdf/ (first: playwright install chromium)
./build.sh --data                 # rebuild data/processed and src/data/*.json from data/raw
./build.sh --labs                 # regenerate and execute the lab notebooks
```

Math is rendered to HTML at build time, so the pages need no JavaScript to show formulas; charts and the interactive figures use a small dependency-free script (`src/assets/book.js`).

## Hosting on your own domain

Every link in `docs/` is relative, so the site works at a domain root or under a sub-path.

- **GitHub Pages:** Settings → Pages → *Deploy from a branch* → `main` / `/docs`. For a custom domain, add a file `docs/CNAME` containing the domain (for example `quant.example.com`) and point a DNS `CNAME` record at `benjamin-teng.github.io`.
- **Any static host** (Cloudflare Pages, Netlify, your own server): publish the `docs/` folder; no build step is needed on the host.

## Writing a module

`src/lmNN.md` starts with YAML front matter (`lm`, `title`, `prereq`, `leads`, `cfa`, `outcomes`, `overview`, `js`) followed by Markdown:

| Syntax | Renders as |
|:--|:--|
| `$x$`, `$$…\tag{3.1}$$` | KaTeX inline / numbered display math |
| `## Title {lo=2,3}` · `## Summary {-}` | numbered section mapped to outcomes 2 and 3 · unnumbered section |
| `> [!definition] Term` · `theorem` · `pitfall` · `zh` · `kc` · `case` · `note` | callout boxes (`zh` = 中文導讀) |
| `> [!example] Title {#label}` with a nested `> > [!solution]` | numbered example with its solution |
| `> [!exhibit] Title {#label}` | numbered table or chart; a final `Note:` / `Source:` line becomes the caption |
| `> [!deepdive]- Title`, `> > [!answer]-` | collapsed proof / answer |
| `[[LM14]]`, `[[ex:label]]`, `[[eg:label]]` | links to modules, exhibits, examples (numbered automatically) |
| `<div data-chart="id"></div>` | chart from `src/data/id.json` (hover tooltips, light/dark aware) |

The same files open cleanly in Obsidian, so the sources double as a notes vault.

## Data

Taiwan prices come from FinMind `TaiwanStockPrice` and `TaiwanStockDividendResult`; US prices from FinMind `USStockPrice` (retrieved 2026-10-10). Every daily close in `data/raw/` was checked against FinMind's own `spread` column (close − previous close); the only mismatches are ex-dividend days and the two share splits (0050 4-for-1 on 2025-06-18, 00631L 22-for-1 on 2026-03-31), which the pipeline handles explicitly. See [`data/README.md`](data/README.md).
