# 從基礎數學到 Kelly 部位政策：課綱與寫作建議

日期：2026-10-21。對象：後續 Claude Code 寫手與主編。

## 文件定位

使用者希望「從微積分、線性代數，自學到能用數學工具嚴謹規劃 Kelly 槓桿與部位調控」。
本文保存針對這個目標的課綱評估，供後續擬定 briefs、撰寫教材與設計 capstone 時參考。
本次沒有驗算個別題目、解答或數值，也沒有據此認定任何現有公式錯誤。

**整體判斷：保留現有主線，優先補強跨卷能力驗收與決策整合，不必再增加大量進階數學。**

本文是建議紀錄，不代表所有建議已採用或實作，不取代
[SPEC](../project/SPEC.md)、[AUTHORING](../AUTHORING.md) 與 [ROADMAP](ROADMAP.md)。
brief 起草者與主編應在相關 brief 中說明採用、調整或暫不採用的理由；正式規範與排程由主編維護。
各卷的採用決定記在該卷 brief（`plans/vol-N.md`）的共同決策中。
出版狀態以 [syllabus](../src/syllabus.yaml) 與 [TODO](../TODO.md) 為準，不從本文推定完成進度。

## 保留的課程結構

| 階段 | 對最終能力的作用 | 寫作重點 |
| --- | --- | --- |
| I–II：微積分、線性代數 | 理解複利、近似、最佳化與多資產風險 | 連結標量、向量與矩陣；說清近似條件與數值不穩定 |
| III–IV：機率、統計、時間序列 | 理解分布、相依性、估計誤差與波動變化 | 在尋找最佳槓桿前，先理解輸入為何不可靠 |
| V–VI：投組最佳化、風險與回測 | 在限制下配置，評估樣本外表現與壓力損失 | 將估計、約束、成本與研究衛生連在一起 |
| VII：隨機微積分 | 理解連續時間 Kelly 的推導與模型邊界 | 保留 GBM、Itô 主線；LM40 選擇權橋接維持選修 |
| VIII：Kelly 與槓桿 | 從理想模型走向不確定性、摩擦與工具限制 | 接上可執行的部位規則，而非只呈現最佳解 |
| IX：Capstone | 獨立建立、驗證與監控決策流程 | 用新資料完成整套政策，不能只重現教材績效圖 |

保留螺旋式安排：LM4 先以二元 Kelly 建立動機，後續加入期望與相依性、估計不確定性、
多資產配置與限制條件。後面的章節應清楚說明「這次增加哪一層能力」，避免重複推導而沒有推進。

不要把已規劃的主題誤報為缺漏：估計誤差、收縮、厚尾與跳躍、破產界線、回撤、稅費、
融資、再平衡、保證金、樣本外驗證與監控，均已出現在現有課綱或 roadmap。
真正待落實的是它們的教學深度、彼此接棒方式與整合驗收。

## 優先建議一：加入跨卷累積驗收

單章 knowledge checks、完整解答與重現式 labs 是必要支援，但不能單憑完成這些活動，
就認定讀者已能獨立制定部位政策。建議從第四卷起，讓同一個小型策略案例逐卷成長。

| 時點 | 建議任務 | 可觀察的達標證據 |
| --- | --- | --- |
| 第四卷後 | 從策略報酬估計特性與不確定性 | 能解釋估計方法、相依假設與限制；指出資料尚不支持的結論 |
| 第六卷後 | 在槓桿、換手與成本限制下配置及壓測 | 能完成樣本外比較、情境損失分析，並解釋約束如何改變配置 |
| 第八卷後 | 提出完整槓桿與部位政策 | 能從估計走到目標部位、實際調倉、限制處理與重估規則 |
| 第九卷 | 換一份資料，從空白 notebook 獨立完成 | 能重建整套流程，說明設計理由與失效條件，而非套用現成答案 |

這些驗收可以沿用既有資料與 lab，不必各增加一套大型專案。
貫穿案例用於練習；最終獨立任務須避免讀者只是記住同一份資料的答案。

## 優先建議二：區分熟練程度，緩衝內容密度

每章 brief 建議區分三種學習成果：

1. **必須能推導：**不看解答也能重建核心論證，並交代前提與近似。
2. **必須能實作與診斷：**能計算、檢查輸入與結果，辨識方法失效的情境。
3. **先理解用途與限制：**知道何時需要此工具，細節可在應用時回查。

優先注意 LM12（矩陣分解與最小平方法）、LM20（估計理論）及 LM45
（參數不確定性、厚尾、跳躍、再平衡、融資與 bootstrap）的密度。
這是教學負擔的提醒，不是要求刪除主題；可用分節、回顧練習或分段 lab 消化。
單章標示的閱讀時間也不應直接當成達到熟練的時間。

VII 卷寫作時應檢查條件期望、資訊隨時間增加、非預知性、收斂與二次變差等概念的銜接。
不要只依賴讀者接受符號操作，也不要將整套測度論或 HJB／隨機控制新增為所有人的必修。
離散時間 Kelly 可以嚴謹建立；隨機微積分則服務於連續時間推導與模型理解，兩者定位需清楚。

## 優先建議三：把目標槓桿接成持續調控的政策

LM44–50 建議共用一個可追蹤的決策流程：

> 當時可取得的資料 → 估計與不確定性 → 目標部位 → 從現倉調整 →
> 成本與財富更新 → 限制檢查 → 下一次決策。

brief 與案例應明確交代以下問題：

- 決策時看得到哪些資料？估計與交易各在什麼時間發生？
- 如何從估計與不確定性決定目標部位？如何從目前持倉調整到目標？
- 再平衡、交易成本、融資成本與現金如何進入財富遞推？
- 何時重估、減碼、不交易或停止使用模型？什麼證據支持恢復？
- 跳空、相關性變化、流動性限制或保證金壓力下，規則是否仍可執行？

減碼、停用與恢復的規則必須有目標、模型或操作限制作依據；不預設任意停損規則都能改善 Kelly。
將定期重估與風險觸發的部位調整分開說明，避免把所有行為含混稱為「動態調整」。

### 貫通財富、可行域與不同失敗形式

用同一案例區分：成長率不理想、觸及回撤限制、資金或保證金不足、財富不再為正。
這些不是同一種失敗，也不能互相替代檢查。

明確定義所用回撤：相對初始資金的跌幅，或相對歷史高點的回撤。
引用機率界限時，保留其風險定義與模型假設，不能直接當成真實市場的保證。
成本後財富為零或負值、單期淨報酬不高於 -100% 等結果域邊界，應明確判為不可繼續套用對數成長，
不能靠忽略情境或截斷數值掩蓋。情境內維持財富正值，也不代表已涵蓋所有未見損失。

保留 roadmap 對 Kelly 適用目的的區分：log utility、有限期間表現、提款／負債需求、
生存或短缺限制，以及回撤約束。案例應實際選定目標與限制，不只在前言提醒一次。

## Capstone 的建議驗收標準

最終產出應是一份可重現、可解釋，也能被新證據推翻的部位政策，至少包含：

- 目標函數、投資期限、報酬定義、資料時序、模型假設與可行域。
- 估計方法及不確定性，以及不確定性如何改變部位決策。
- 成本與融資後的財富、曝險遞推，以及可執行的調倉規則。
- 厚尾、跳空、相依性變化及保證金情境下的限制檢查。
- 不偷看未來的樣本外比較、參數敏感度與可重現結果。
- 降低槓桿、暫停模型、重新估計與恢復使用的依據。

評估前先固定估計視窗、更新頻率、風險限制、成本假設與比較準則；若要選參數，
將選擇流程放在訓練／驗證資料內，保留最終評估資料。
至少比較合理的固定部位、波動率目標與 Kelly 類方法，並交代各自風險預算與限制。
比較不只看報酬，也看成本後成長、回撤、限制違反、追繳情境與敏感度。

**「資料不足，目前不支持增加槓桿」也可以是合格結論。**
不能以最好看的回測績效取代推理品質，也不能以推得最佳解取代實務可行性。

## 後續寫手如何使用本文

1. 先讀 CLAUDE.md 指定的專案文件，再核對相關模組的現行 scope 與先備關係。
2. 在 brief 記錄本文哪些建議適用，以及讀者將交出什麼可觀察成果。
3. 列清本章接收的先備能力、本章新增能力，以及交給後章處理的問題。
4. 完成教材後，依既有獨立驗證流程檢查學習成果是否真的被教到、練到與驗收到。

本文不啟動教材改寫、題目驗證或網站改版，也不更動現有出版關卡。
