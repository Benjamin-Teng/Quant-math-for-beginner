# LM1 Lab — Exponentials, Logarithms and Compounding

Companion to *From Calculus to Kelly*, Learning Module 1. The notebook rebuilds every exhibit and computational example of the module (the 0050 case, log-scale charts, compounding tables, return conversions and trailing returns, aggregation examples, drawdown episodes) and solves the computational practice problems.

## Run

From the repository root:

```bash
uv sync                  # install the locked Python environment (uv.lock)
uv run --with jupyterlab jupyter lab labs/LM01_lab/LM01_lab.ipynb
```

The notebook is saved with its outputs, so you can read it before running it. It is generated by `build/make_lab01.py` (`uv run python build/make_lab01.py` from the repository root) and re-executed from inside this folder with:

```bash
uv run jupyter nbconvert --to notebook --execute --inplace LM01_lab.ipynb
```

## Data (FinMind; not in the repository)

The notebook reads FinMind files that you download once with your own token. From the repository root, run `uv run python data/fetch_finmind.py`, then `uv run python data/make_lab_data.py`:

```bash
export FINMIND_TOKEN=...              # your FinMind API token
uv run python data/fetch_finmind.py   # rebuild data/raw/, checked against
                                      # data/raw_manifest.json
uv run python data/make_lab_data.py   # write this lab's data/ and every
                                      # other lab's
```

FinMind's licence does not allow the book to redistribute the data, so `data/` is git-ignored. After that, the notebook runs offline. The folder then holds the files the module was computed from (FinMind, retrieved 2026-10-10):

| File | Content |
|:--|:--|
| `data/0050_daily_raw.csv` | 0050 daily close and FinMind `spread`, 2014-10-31 → 2026-10-08 (unadjusted) |
| `data/00631L_daily_raw.csv` | 00631L daily close and `spread`, same period (unadjusted) |
| `data/0050_dividends.csv` | 0050 ex-dividend dates and cash dividends (`TaiwanStockDividendResult`) |

Every close matches FinMind's own `spread` column (close − previous close) except on 0050's 22 ex-dividend days in the window and the two split days: 0050 4-for-1 on 2025-06-18 and 00631L 22-for-1 on 2026-03-31. Part 1 of the notebook re-runs this check.

Two daily series are built. The module's case series aligns 0050 with 00631L on their common trading days, as in LM3, and has $T=2{,}902$ daily returns; 0050's own series has 2,906 returns because it keeps four March 2026 sessions on which 00631L did not trade. Growth factors, drawdowns and recovery dates are identical in both. 00631L is needed only for the portfolio example (Part 5) and the extension exercise.

## Conventions (as in the module)

- The span between two dated closes is $\tau=$ calendar days ÷ 365.25; the deposit and card interest of the module's Section 3 accrue on an actual/365 basis.
- $A$ is the number of returns per year used to annualize, quoted from the sample in use: $A=T/\tau=243.1$ for the case series; the exchange averaged 243.8 sessions a year in 2015–2025.
- A drawdown $\mathrm{DD}=1-W/\text{running peak}$ is a positive number; the running peak includes the starting value.
- Exhibit and example numbers in the notebook are generated from the labels in `src/lm01.md`, so they always match the module.
